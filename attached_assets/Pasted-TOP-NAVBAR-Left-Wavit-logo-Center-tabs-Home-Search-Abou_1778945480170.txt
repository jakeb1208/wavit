GLOBAL DESIGN SYSTEM

Apply the exact same visual style, spacing system, color palette, animation style, glow effects, typography hierarchy, and component design across ALL pages, sections, buttons, cards, forms, modals, navigation elements, and interactive components.

The website/app should feel like one unified premium design system, not separate pages with inconsistent styling.

DESIGN LANGUAGE:

* Futuristic minimalism
* Premium dark-mode-first aesthetic
* Soft glassmorphism
* Smooth gradients
* Subtle neon glow accents
* Layered depth
* Elegant spacing
* Extremely polished and modern

COLOR SYSTEM:

* Primary background: deep near-black / charcoal
* Secondary surfaces: dark translucent glass panels
* Accent colors:

  * electric blue
  * soft purple
  * subtle cyan glow
* Use gradients carefully and consistently
* Keep strong contrast while maintaining a clean premium feel

BUTTON SYSTEM:

* Consistent rounded pill-shaped buttons
* Smooth hover and press animations
* Soft glowing active states
* Same padding, shadows, border radius, and typography throughout the entire app/site
* Primary buttons should use glowing gradients
* Secondary buttons should use glassmorphism/outlined styles

TYPOGRAPHY:
Use “Inter” as the primary font across the entire platform.

Typography style:

* Large bold modern hero text
* Clean medium-weight subheadings
* High readability
* Minimal clutter
* Similar typography feel to:

  * Linear
  * Stripe
  * Vercel
  * Notion
  * Apple

Typography hierarchy should remain consistent on every page.

ANIMATIONS:

* Smooth page transitions
* Fade/slide-in effects
* Microinteractions on hover/click
* Floating/glowing ambient effects
* Consistent animation timing and easing across the whole platform

IMPORTANT:
Every page should immediately feel recognizable as part of the same Wavit design ecosystem.
Do not allow inconsistent colors, fonts, spacing, or component styles between pages.
